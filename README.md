# Healthcare Patient Analytics Dashboard

## Project Overview
I developed an interactive Power BI dashboard focused on Healthcare Analytics. The goal of this project is to provide actionable insights into patient demographics, hospital department operations, and treatment costs to help improve healthcare management decision-making.

## Key Features & Metrics
* **Total Patients & Financials:** Tracked total patient influx (5K) and computed the overall average cost of treatments (54.92K).
* **Department Performance:** Analyzed and visualized the average treatment cost across different hospital departments using a Clustered Bar Chart.
* **Patient Demographics:** Developed a clean Donut Chart to show the gender-wise distribution of patients (Male vs. Female split).
* **Interactive Filtering:** Integrated an advanced Slicer (Tile buttons) for treatment_type to allow dynamic filtering across the entire dashboard.

## Tech Stack Used
* **Data Cleaning & Transformation:** Python (Pandas)
* **Data Visualization & Dashboarding:** Microsoft Power BI
* **Design Philosophy:** Modern UI with custom layouts and rounded visual containers.
